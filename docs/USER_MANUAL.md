# ForgeAtoms 用户手册

欢迎使用 **ForgeAtoms（AI 多智能体产品工坊）**。本手册说明如何注册、创建项目、启动多智能体构建，以及使用竞速 A/B 与 ZIP 导出。

## 1. 访问地址

- **公网 Demo（可选）**：本地 `npm start` 后可用；若运行 `scripts/restart-all.sh` 且已安装 cloudflared，临时地址会写入 gitignored 的 `DEPLOY_URL.txt`
- **本机**：http://127.0.0.1:3847/

## 2. Demo 账号（可直接登录）

| 字段 | 值 |
|------|-----|
| 邮箱 | `demo@forgeatoms.local`（由 `npm run seed` 创建） |
| 密码 | 见 seed 脚本输出 / `src/seed.js`（仅 Demo） |

也可以在首页点击「注册」创建自己的账号。

## 3. 基本使用流程

### 3.1 注册 / 登录

1. 打开首页，点击 **注册** 或 **登录**。  
2. 注册需填写昵称（可选）、邮箱、密码（至少 6 位）。  
3. 登录成功后进入 **工作台**。

### 3.2 创建项目

1. 点击 **新建项目**（或工作台右上角）。  
2. 填写：  
   - **项目标题**：例如「夜跑伙伴」  
   - **想法描述**：用自然语言写清目标用户、核心功能、场景等  
   - **交付物类型**：网站 / PPT / 小游戏 / 自动识别  
3. 提交后进入该项目的 **工作区**。

### 3.3 启动多智能体构建（核心主流程）

1. 在工作区点击 **启动构建**。  
2. 左侧 **智能体时间线** 会依次出现：  
   - 🔍 **Iris（调研）** — 品类、语气、用户与关键词  
   - 🧭 **Emma（产品）** — 价值主张、CTA、MVP 能力  
   - 🏗️ **Bob（架构）** — 页面结构与技术草案  
   - ⚙️ **Alex（工程）** — 交付说明  
3. 状态从「草稿 → 调研中 → 构建中 → 已就绪」。  
4. 右侧 **预览** 出现生成的着陆页（iframe）。可点击预览内链接查看「关于」副页。

> 网站与 PPT 均调用 **DeepSeek API**（环境变量 `DEEPSEEK_API_KEY`）。网站在 API 失败时会回退到离线启发式。

## 4. 延展能力

### 4.1 竞速模式（Race Mode）

在项目 **已就绪** 后：

1. 点击 **竞速生成 A/B**。  
2. 系统生成两套着陆设计：  
   - **Variant A**：经典英雄区 + 功能卡片  
   - **Variant B**：分割布局 + 社交证明  
3. 可在预览顶部切换 A/B，或在下方 **竞速对比** 并排查看。  
4. 点击 **选用此版本**，该版本成为导出默认项。

### 4.2 导出 ZIP

1. 确认已选用目标版本（或在导出链接中指定）。  
2. 点击 **导出 ZIP**。  
3. 压缩包内容：  
   - `index.html` — 着陆页  
   - `about.html` — 关于 / SEO 副页  
   - `README.md` — 简要说明  

可用任意静态服务器打开（例如 `npx serve .`）。


## 4.5 PPT 演示文稿（DeepSeek）

1. 新建项目时，**交付物类型**选「PPT 演示文稿」，或在想法里写「PPT / 幻灯片 / 演示文稿」等关键词（自动识别）。  
2. 示例标题：`央视春晚回忆录`；想法写清页数与要覆盖的章节。  
3. 点击 **启动构建**：Iris 调研 → Emma 大纲 → Bob 设计 → Alex 生成 `.pptx`（约 1–3 分钟）。  
4. 右侧显示 **大纲预览**（幻灯片卡片）；点击 **下载 PPTX** 获取真实 PowerPoint。  
5. **导出 ZIP** 含 `presentation.pptx`、`outline.json`、`design.json`、`README.md`。  
6. PPT 项目不提供竞速 A/B；改想法后重新构建即可。

## 5. 工作台与项目管理

- 工作台列出你的全部项目与状态。  
- 进入项目可重新构建、竞速、导出。  
- **删除** 会移除项目及产物（不可恢复）。

## 6. 常见问题

**Q: 预览是空白的？**  
A: 请先完成一次「启动构建」并等待状态变为「已就绪」。若仍空白，刷新页面或检查是否已登录。

**Q: 竞速按钮是灰的？**  
A: 仅在 `已就绪` 且当前无构建任务时可用。

**Q: 公网链接打不开？**  
A: Tunnel 为临时 Quick Tunnel，进程退出后会失效。请让维护者按 `docs/TECHNICAL.md` 重启服务与隧道，或查看最新的 `DEPLOY_URL.txt`。

**Q: 密码忘了？**  
A: Demo 环境无找回流程；可重新注册，或使用 Demo 账号。

**Q: 和 atoms.dev 有何区别？**  
A: 本 Demo 已接入 DeepSeek 真实大模型，可生成着陆页文案与可下载 PPTX；仍为教学演示规模，不含 atoms.dev 商业云托管全套能力。

## 7. 推荐体验路径（约 3 分钟）

1. 用 Demo 账号登录  
2. 新建「夜跑社交 App」类想法  
3. 启动构建 → 看时间线与预览  
4. 竞速生成 → 选用 B  
5. 导出 ZIP 并本地打开 `index.html`


## 8. PPT 推荐体验路径

1. Demo 账号登录  
2. 新建：标题「央视春晚回忆录」，交付物选 PPT，想法写约 10 页中文回忆录要求  
3. 启动构建 → 等待就绪  
4. 预览大纲 → 下载 PPTX 用 PowerPoint / WPS / Keynote 打开

## 4.6 小游戏（可玩 HTML5）

1. 新建项目时选「小游戏」，或在标题/想法中写「2048 / 贪吃蛇 / 俄罗斯方块 / 小游戏」等。  
2. 点击 **启动构建**：智能体判定游戏类型；DeepSeek（若已配置）润色标题与配色；**玩法逻辑使用本地可信模板**，保证可玩。  
3. 右侧预览 iframe 中 **点击游戏区域**，用方向键（或触屏滑动）游玩；可重新开始、计分。  
4. **导出 ZIP** 含 `index.html`、`game.json`、`README.md`。  
5. 小游戏不提供竞速 A/B。

支持：2048、贪吃蛇、俄罗斯方块。

## 4.7 视频 / 音频（多模态兜底）

若想法的**主要交付**是视频、短片、音频、配音、播客、歌曲等，系统**不会**调用视频/音频 API。构建完成后会显示：

> **多模态模型API额度用尽，请及时充值**

并提示：当前 Demo 支持网站 / PPT / 小游戏；视频与音频生成需充值多模态额度后再试。


## 4.8 像素风 UI 与素材库

- 全站采用星露谷物语风格的像素 UI（大地色、粗边框、像素字体）。
- 打开 **[素材库](/assets-library)** 可浏览人物 / 树木 / 花草 / 水果 / 美食 / 场景精灵图。
- 做 **PPT** 或 **像素海报/图片** 时：智能体先理解主题关键词，再从素材库匹配 4–8 张素材，用羊皮纸面板拼贴成封面/海报；PPT 内容页还会点缀相关图标。

## 4.9 像素海报 / 图片

1. 新建时交付物选「像素海报 / 图片」，或想法里写「海报 / 图片 / 插画 / 封面图」。  
2. 启动构建 → 预览拼贴图 → **下载海报 PNG** 或导出 ZIP（含 `poster.png`、`collage.json`）。  
3. 图片交付**不会**触发多模态额度用尽；仅视频/音频走该兜底。
